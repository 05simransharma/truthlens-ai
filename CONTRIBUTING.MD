# CONTRIBUTING

Thank you for your interest in contributing to TruthLens AI.

This project was developed as part of a hackathon and demonstrates the use of Generative AI for contract risk analysis and news credibility assessment.

---

## How to Contribute

1. Fork the repository.
2. Create a new feature branch.

```bash
git checkout -b feature-name
```

3. Make your changes.
4. Test the application locally.

```bash
uv sync
uv run streamlit run app.py
```

5. Commit your changes.

```bash
git commit -m "Describe your changes"
```

6. Push to your fork.

```bash
git push origin feature-name
```

7. Create a Pull Request.

* Follow Python best practices.
* Write clear and maintainable code.
* Keep modules small and focused.

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue with:

* Description
* Steps to reproduce
* Expected behavior
* Screenshots (if applicable)
